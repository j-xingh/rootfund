# Rootfund symbol-only logo assets

This package contains editable SVG logo-symbol variants. No wordmark or text is included.

## Files
- `rootfund-symbol-primary.svg` — full-colour symbol on transparent background
- `rootfund-symbol-burgundy.svg` — single-colour burgundy symbol
- `rootfund-symbol-ivory.svg` — single-colour soft-blush/ivory symbol
- `rootfund-symbol-on-burgundy.svg` — full-colour symbol on burgundy tile
- `rootfund-symbol-on-emerald.svg` — full-colour symbol on emerald tile
- `rootfund-symbol-on-blush.svg` — burgundy monochrome symbol on blush tile
- `rootfund-app-icon.svg` — square app icon
- `rootfund-favicon.svg` — compact favicon SVG

## Brand colours
- Deep Burgundy: `#37162B`
- Emerald: `#006853`
- Orange: `#F56504`
- Golden Yellow: `#F2D000`
- Lavender: `#A291E1`
- Soft Blush: `#F4EEEE`

## Usage
Use the transparent primary SVG for the website header and the app icon / favicon variants for small-format contexts. Keep the SVGs as vector assets; do not rasterize unless a platform specifically requires PNG.
